# Licences in this repository

Every file carries (or inherits from its folder) one SPDX identifier. The repository ships under Apache-2.0: code, weights
and docs together (see [docs/LICENSING.md](../docs/LICENSING.md)).

| Part | Where | SPDX | Why |
|---|---|---|---|
| Code: model runtime, validator, world builder, game runtime, data generator, trainer, tools, tests | `src/`, `tools/`, `tests/`, `index.html` | `Apache-2.0` | Same licence as the other slm4apps projects; patent grant; permissive |
| Game packs (data) | `packs/` | `Apache-2.0` | Part of the repository licence |
| Model weights, manifest, item library | `models/` (`terraville-tiny.bin`, `terraville-tiny.json`, `library.json`), the Hugging Face model repo | `Apache-2.0` | Trained from scratch on synthetic data, no base model. Provenance of the item library: see docs/LICENSING.md |
| Benchmark and test sets (synthetic) | `data/` | `Apache-2.0` | Generated by `tools/gen_tiny.py` |
| Documentation, card, figures, brand files | `*.md`, `assets/` | `Apache-2.0` | Part of the repository licence |
| three.js (bundled, unmodified) | `vendor/` | `MIT` | Its own licence and header, text in `MIT-three.js.txt` |

Texts: `Apache-2.0.txt`, `MIT-three.js.txt`.
No part of this repository imports Blender's Python API, so no GPL-licensed part applies. There is no base model: Terraville is
trained from scratch, so no base-model licence applies.
